# Легче 2.0

Андроид-приложение для безопасного похудения: калории и БЖУ, дневник на 835 продуктов, вода, вес и замеры, давление и глюкоза с правилами безопасности, 130 рецептов с учётом вашей кухни (в том числе мультиварки), корзина перед неделей, силовая программа под ваши гантели, резинки и степпер, особые периоды (застолье, поездка, болезнь), награды за привычки. Работает офлайн; рецепты и продукты обновляются через интернет без переустановки.

- **Обновление до 2.0, база рецептов и продуктов, версии, штрихкоды:** [docs/INSTRUCTION_2.0.md](docs/INSTRUCTION_2.0.md)
- Сборка APK на GitHub (первая установка): [docs/BUILD.md](docs/BUILD.md)
- Техническое задание 1.0: [docs/TZ.md](docs/TZ.md)

## Структура

```
www/                 приложение (HTML, CSS, JS)
content/             рецепты, продукты, советы + manifest.json (редактируются без переустановки)
ci/                  сборка: подпись, патч Android, проверка контента, иконки
tools/               исходник рецептов (необязательно)
tests/               автотесты логики и проверка интерфейса в браузере
.github/workflows/   build-apk.yml (APK) и content.yml (проверка рецептов)
```

## Проверка на компьютере

```
npm install
python3 ci/build_content.py --auto --copy   # проверить контент и скопировать в www/content
npm test                                    # логика, рецепты, миграции
python3 tests/smoke2.py                     # интерфейс в браузере (нужен playwright)
```

Релиз: **Releases → Draft a new release → тег `v2.0.1` → Publish**. Через 10–15 минут APK появится в релизе.
