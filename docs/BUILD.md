# Сборка APK на GitHub: пошаговая инструкция

Нужны: компьютер (или планшет) с браузером, аккаунт GitHub (бесплатный). Установка программ не требуется: сборку выполняет GitHub.

## Часть 1. Подготовка репозитория

1. Зарегистрируйтесь на https://github.com (если аккаунта нет). Подтвердите почту.
2. Нажмите **«+» → New repository** (правый верхний угол).
   - Repository name: `legche`
   - Public (так APK скачивается без входа с телефона). В приложении нет личных данных: они хранятся только на телефоне.
   - Ничего больше не отмечайте. Нажмите **Create repository**.
3. Распакуйте архив `legche.zip` на компьютере. Внутри должна быть папка `legche` с файлами `package.json`, `capacitor.config.json`, папками `www`, `ci`, `assets`, `docs`, `tests`, `.github`.
   - На Windows скрытые папки (`.github`) нужно показать: Проводник → Вид → Показать → Скрытые элементы. На Mac: Cmd+Shift+. (точка).
4. На странице нового репозитория нажмите ссылку **uploading an existing file**.
5. Выделите **всё содержимое** папки `legche` (не саму папку, а то, что внутри) и перетащите в окно браузера. Дождитесь окончания загрузки всех файлов и папок.
6. Внизу нажмите **Commit changes**.

### Если папка `.github` не загрузилась
1. В репозитории нажмите **Add file → Create new file**.
2. В поле имени введите точно: `.github/workflows/build-apk.yml` (косые черты создадут папки).
3. Откройте файл `build-apk.yml` из архива в блокноте, скопируйте всё содержимое и вставьте в окно GitHub.
4. Нажмите **Commit changes**.

### Если вы пользуетесь git
```
cd legche
git init
git add .
git commit -m "Легче 1.0"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/legche.git
git push -u origin main
```

## Часть 2. Сборка и релиз

### Вариант А (рекомендуется): создать релиз
1. В репозитории откройте справа **Releases → Create a new release**.
2. В поле **Choose a tag** введите `v1.0.0` и нажмите **Create new tag: v1.0.0 on publish**.
3. Release title: `Легче 1.0.0`. Нажмите **Publish release**.
4. Откройте вкладку **Actions**. Появится запуск «Сборка APK» с жёлтым индикатором. Сборка идёт 6–12 минут.
5. Когда индикатор станет зелёным ✅, вернитесь в **Releases**: в релизе `v1.0.0` в разделе **Assets** появится файл `Legche-1.0.0.apk`.

### Вариант Б: ручной запуск
1. Вкладка **Actions** → слева «Сборка APK» → справа **Run workflow**.
2. Введите версию (например `1.0.0`), оставьте галочку «Опубликовать релиз», нажмите **Run workflow**.
3. Через 6–12 минут APK появится в Releases (и в самом запуске, раздел Artifacts).

### Если запуск красный ❌
1. Откройте запуск в **Actions**, нажмите на красный шаг.
2. Скопируйте последние 30–40 строк лога и пришлите их мне: исправлю.
3. Если во вкладке Actions написано, что workflow отключены, нажмите **I understand my workflows, go ahead and enable them**.

## Часть 3. Установка на телефон

1. На телефоне откройте в браузере страницу релиза: `https://github.com/ВАШ_ЛОГИН/legche/releases`.
2. Нажмите на `Legche-1.0.0.apk` и скачайте файл.
3. Откройте скачанный файл. Android предложит разрешить установку из этого источника (браузера): разрешите.
4. Если Google Play Protect предупредит о неизвестном приложении, выберите «Подробнее → Всё равно установить».
5. Откройте «Легче», создайте профиль. Второй человек ставит тот же APK на свой телефон (или добавляет второй профиль на одном телефоне).

## Часть 4. Настройка напоминаний (важно)

1. В приложении: шестерёнка → **Напоминания** → включите, выберите дни и часы → **Сохранить и применить** → разрешите уведомления.
2. Нажмите **Тест уведомления**: через 4 секунды должно прийти сообщение.
3. Чтобы напоминания приходили при закрытом приложении, в настройках телефона:
   - Настройки → Приложения → Легче → Батарея → **Без ограничений**.
   - Xiaomi/Redmi/Poco: «Автозапуск» включить, «Экономия заряда» → «Нет ограничений».
   - Samsung: «Батарея → Фоновое использование → Никогда не усыплять» для «Легче».
   - Huawei/Honor: «Запуск приложений» → Легче → вручную, включить все три переключателя.
   - Realme/Oppo/Vivo: «Автозапуск» и «Работа в фоне» включить.
   - Android 12+: кнопка «Точные будильники» в приложении откроет нужный пункт.

## Часть 5. Обновления

1. Внесите изменения в файлы репозитория (или пришлите мне, я подготовлю).
2. Создайте новый релиз с новым тегом: `v1.0.1`, `v1.1.0` и так далее.
3. Скачайте новый APK и установите **поверх** старого: данные сохранятся (подпись одинаковая).
4. Перед обновлением сделайте копию: Настройки → Сохранить копию.

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| «Приложение не установлено» | Удалите старую версию из другого источника (если была) или освободите память. Данные предварительно экспортируйте. |
| Нет кнопки установки | Разрешите установку из браузера: Настройки → Приложения → особые права → Установка неизвестных приложений. |
| Уведомления не приходят | Проверьте разрешение для «Легче» → Уведомления, режим «Не беспокоить», батарею (часть 4). |
| Данные пропали после переустановки | Установите резервную копию: Настройки → Загрузить из файла. |
| Актуальные версии библиотек сломали сборку | Пришлите лог, поправлю версии в `package.json`. |
