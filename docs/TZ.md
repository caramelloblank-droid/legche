# Техническое задание: приложение «Легче»

Версия документа: 1.0 · Платформа: Android (APK) · Язык интерфейса: русский

## 1. Цель и контекст

**Цель.** Помочь людям с большим избыточным весом безопасно худеть: считать норму калорий, вести дневник питания, воду, вес, давление и сахар, давать мягкую физическую нагрузку, напоминать о привычках и мотивировать наградами за *действия*, а не только за килограммы.

**Первые пользователи.** Пара: мужчина (рост 183 см, вес 150+ кг) и женщина (рост 172 см, вес 120+ кг), образ жизни очень малоподвижный (дом, дорога на работу, сидячая работа). Есть домашние тонометр и глюкометр. Обращение к врачу на старте не предполагается.

**Принципы.**
1. Расчёты не привязаны к конкретным людям: всё считается из введённых пола, возраста, роста, веса и образа жизни.
2. Безопасность прежде скорости: ограничения дефицита и нагрузок при плохих показателях давления и сахара.
3. Награда за привычки (запись еды, вода, движение, замеры), а не за скорость похудения. Недоедание не поощряется.
4. Всё работает без интернета, данные хранятся только на телефоне.
5. Бюджетность: упор на недорогие продукты и блюда.

## 2. Платформа и архитектура

| Решение | Выбор | Обоснование |
|---|---|---|
| Формат | Android-приложение (APK), сборка на GitHub | Нужны локальные уведомления без сервера |
| Технология | HTML/CSS/JS в оболочке Capacitor 6 | Один код, быстрая сборка, без Android Studio |
| Хранение | localStorage WebView (JSON) | Без сервера, офлайн, приватно |
| Уведомления | Плагин Capacitor Local Notifications | Работают при закрытом приложении и без интернета |
| Резервная копия | JSON-файл через «Поделиться» + копирование текстом | Данные не теряются при переустановке |
| Распространение | GitHub Releases (APK скачивается с телефона) | Google Play не нужен |
| Минимальная версия | Android 8.0+, обновлённый Android System WebView | Современный JavaScript |

Сборка: GitHub Actions (`.github/workflows/build-apk.yml`) — установка зависимостей, автотесты расчётов, генерация Android-проекта, патч манифеста, сборка APK, публикация релиза. APK подписывается постоянным ключом из репозитория (`ci/debug.keystore`), поэтому обновления ставятся поверх без потери данных.

## 3. Функциональные требования

### 3.1 Профили (FR-1)
- FR-1.1 Неограниченное число профилей на устройстве (режим пары на одном телефоне).
- FR-1.2 Поля: имя, пол, возраст, рост, текущий вес, образ жизни (множители 1,2 / 1,375 / 1,55 / 1,725), процент дефицита (10–25%), целевой вес.
- FR-1.3 Целевой вес по умолчанию: −15% от стартового (этапная цель).
- FR-1.4 Переключение и удаление профилей, удаление с подтверждением.

### 3.2 Расчёт калорий и нутриентов (FR-2)
- FR-2.1 Базовый обмен: формула Миффлина — Сан Жеора.
- FR-2.2 Суточный расход = обмен × коэффициент образа жизни.
- FR-2.3 Дефицит = min(процент × расход, 1000 ккал).
- FR-2.4 Нижний предел: 1500 ккал (мужчины), 1200 ккал (женщины); норма не ниже предела и не выше расхода.
- FR-2.5 Белок = 1,6 г на кг «расчётной массы» (идеальная масса по ИМТ 25 + 25% излишка), в пределах 20–35% калорий. Жиры 30% калорий, остальное — углеводы. Клетчатка 14 г на 1000 ккал.
- FR-2.6 Норма воды = 30 мл на кг, не менее 1500 и не более 3000 мл.
- FR-2.7 Автопересчёт нормы, когда сглаженный вес отклонился на 3 кг от веса последнего расчёта; пользователь видит уведомление.
- FR-2.8 «День с запасом»: один выбранный день недели +15% к норме, остальные дни автоматически ниже так, чтобы среднее за неделю не изменилось.
- FR-2.9 Предупреждения: слишком быстрое снижение (>1,2% веса в неделю), плато более 3 недель, мало записанных калорий вечером.

### 3.3 Дневник питания (FR-3)
- FR-3.1 Приёмы: завтрак, обед, ужин, перекус. Навигация по датам, правка записей задним числом.
- FR-3.2 Встроенная база более 800 продуктов и блюд на 100 г (ккал, белки, жиры, углеводы): крупы, хлеб, мясо, птица, рыба, колбасы, молочное, сыры, овощи, фрукты, орехи, бобовые, грибы, соусы, сладкое, напитки, алкоголь, фастфуд, домашние блюда и супы, спортпитание.
- FR-3.3 Поиск по части слова, офлайн; сырые/сухие позиции ранжируются ниже готовых.
- FR-3.4 Порции в штуках/ложках/стаканах там, где это известно.
- FR-3.5 Свои продукты (с упаковки) и свои рецепты (ингредиенты → калорийность порции).
- FR-3.6 Избранное, недавние, «как вчера», быстрая запись только калорий.
- FR-3.7 Индикатор «осталось ккал» и баланс Б/Ж/У.

### 3.4 Вода (FR-4)
- FR-4.1 Кнопки +200/+250/+500 мл, «−250», свой объём. Шкала дня.
- FR-4.2 Привычка «вода» засчитывается при ≥80% нормы.

### 3.5 Вес и замеры (FR-5)
- FR-5.1 Ввод веса с датой, история, удаление.
- FR-5.2 Скользящее среднее за 7 дней («тренд») — основная величина для целей и наград.
- FR-5.3 График, темп за неделю, прогноз даты цели (по тренду 28 дней).
- FR-5.4 Этапы −5/−10/−15% с индикаторами.
- FR-5.5 Замеры: талия, бёдра, грудь; график; показатель «талия/рост» (ориентир <0,5).

### 3.6 Давление и сахар (FR-6)
- FR-6.1 Журнал давления (верхнее, нижнее, пульс, дата/время) и глюкозы (ммоль/л; натощак / через 2 часа). Графики, средние.
- FR-6.2 Зоны давления: норма <130/85; внимание 130–139 или 85–89, а также <90/60; повышено ≥140/90; опасно ≥180/120.
- FR-6.3 Зоны глюкозы: натощак 3,9–5,5 норма, 5,6–6,9 повышено, ≥7,0 вне нормы; через 2 часа до 7,7 норма, 7,8–11,0 повышено, ≥11,1 вне нормы; <3,9 низкий.
- FR-6.4 **Правила безопасности (обязательные):**
  - ≥180/120 (в последние 6 часов): режим «нагрузки отменены», перемерить через 15 минут, при симптомах — скорая.
  - Два последних замера подряд ≥140/90 (в пределах суток): только разминка сидя и спокойная ходьба до 10 минут.
  - <90/60 (в последние 6 часов): только лёгкие упражнения сидя.
  - Натощак ≥7,0 или любое значение <3,9 за 14 дней: дефицит калорий ограничивается 10%.
  - Приложение не ставит диагнозов и не назначает лечение.

### 3.7 План питания и покупки (FR-7)
- FR-7.1 Автоматический план на день и неделю: завтрак (25%), перекус (10%), обед (30%), перекус (10%), ужин (25%) от нормы.
- FR-7.2 Библиотека из 44 блюд на недорогих продуктах с граммовкой, подбираемой под норму конкретного человека, и советами по приготовлению.
- FR-7.3 Повторение блюд внутри недели (готовка на 2–3 дня) для экономии времени и денег.
- FR-7.4 Настройки: бюджет блюд (самые дешёвые / недорогие / любые), день с запасом, «Другое меню на неделю».
- FR-7.5 Кнопка «В дневник» переносит блюдо в дневник с калорийностью.
- FR-7.6 Список покупок на неделю или остаток недели, для себя или для всех профилей, с отметками купленного, примерной стоимостью и редактируемыми ценами.
- FR-7.7 Раздел «Бюджетная корзина»: базовый набор, ориентировочные цены, правила экономии.

### 3.8 Движение (FR-8)
- FR-8.1 Только малоударные упражнения: сидя, стоя у опоры, у стены. Без прыжков, бега, упражнений на полу и глубоких приседаний.
- FR-8.2 Программа по неделям: недели 1–2 (6 мин + ходьба 10 мин), 3–4 (10 + 15), 5–8 (15 + 20), 9–12 (20 + 30), 13+ (25 + 40). При ИМТ ≥40 уровень не выше третьего, время упражнения 30 секунд.
- FR-8.3 Основная разминка и мини-разминка (2–3 минуты) с таймером, отдыхом, звуком и вибрацией; логирование времени и ориентировочных калорий.
- FR-8.4 Журнал ходьбы по минутам.
- FR-8.5 Библиотека упражнений с описанием и предупреждением о коленях.
- FR-8.6 Постоянная памятка «Остановитесь, если…».
- FR-8.7 Сожжённые калории только информативны и не увеличивают норму еды.

### 3.9 Мотивация (FR-9)
- FR-9.1 **Привычки дня** (все три → день засчитан): еда записана (не менее 75% нижнего предела калорий, чтобы не поощрять голодание), вода ≥80% нормы, движение ≥5 минут.
- FR-9.2 **Серия дней** с «заморозкой»: один пропущенный день в каждой календарной неделе не обнуляет серию.
- FR-9.3 **Очки и уровни** (10 званий). Очки считаются из данных заново, их нельзя накрутить повторными нажатиями.
- FR-9.4 **26 достижений**: серии, вода, движение, потеря веса и процентов, талия, давление и сахар в норме 2 недели, идеальная неделя, челленджи.
- FR-9.5 **Недельные челленджи** (3 в неделю из 9), +50 очков за каждый.
- FR-9.6 **Свои награды** за этапы −5/−10/−15%, цель, серию 7 и 30 дней: текст скрыт, пока этап не достигнут.
- FR-9.7 Поздравления с анимацией и вибрацией; не показываются поверх ввода данных.
- FR-9.8 Принцип: быстрое похудение не награждается.

### 3.10 Режим пары (FR-10)
- FR-10.1 Сравнение по **процентам** потери веса, серии и очкам для всех профилей на телефоне.
- FR-10.2 Общий челлендж «30 дней подряд вместе».
- FR-10.3 Если у партнёра свой телефон: обмен текстовым кодом (имя, вес, серия, очки, выполненные дни); код вставляется в приложение.

### 3.11 Уведомления (FR-11)
- FR-11.1 Локальные уведомления Android, без сервера и интернета; переживают перезагрузку телефона.
- FR-11.2 Настройка: рабочие дни, начало/конец дня, обеденное окно без напоминаний, интервал «размяться» (45/60/90/120 мин) и «выпить воды» (60/90/120 мин).
- FR-11.3 Дополнительно: взвешивание раз в неделю, давление 2 раза в день, сахар натощак, запись дневника вечером, напоминание о резервной копии.
- FR-11.4 Разные тексты, три канала уведомлений (вода, разминка, здоровье). Нажатие открывает нужный раздел.
- FR-11.5 Тест уведомления, проверка разрешения «точные будильники», подсказка про энергосбережение.
- FR-11.6 Лимит 450 уведомлений в расписании.

### 3.12 Данные (FR-12)
- FR-12.1 Экспорт всех данных в JSON-файл («Поделиться»), копирование текстом, импорт из файла.
- FR-12.2 Полное удаление данных с двойным подтверждением.
- FR-12.3 Без аккаунтов, без аналитики, без сетевых запросов.

## 4. Экраны

Нижняя навигация: **Сегодня** (кольцо калорий, вода, привычки, серия, челленджи, быстрые записи) · **Дневник** · **План** (день / неделя / покупки / корзина) · **Движение** · **Прогресс** (вес / тело / давление / сахар / награды / пара). Сверху: профиль и настройки.

## 5. Нефункциональные требования

- Офлайн полностью. Объём данных за год — менее 2 МБ.
- Крупные области нажатия (от 44 px), светлая и тёмная тема, поддержка системных отступов и клавиатуры, портретная ориентация.
- Кнопка «Назад» закрывает окна и возвращает на главный экран.
- Приватность: никакие данные не покидают телефон, кроме явного экспорта пользователем.
- Скорость: запуск менее 2 секунд, мгновенный поиск по базе.

## 6. Ограничения (честно)

1. Локальные уведомления составляются заранее: приложение не может «не напоминать о воде, если вы уже выпили норму».
2. Android-производители (Xiaomi, Huawei, Samsung, Realme) агрессивно «усыпляют» приложения: нужно разрешить работу в фоне (инструкция есть в настройках).
3. Таймер разминки работает при включённом экране.
4. Пара на двух телефонах — обмен кодами вручную, не автоматическая синхронизация.
5. Цены продуктов приблизительные, редактируются пользователем.
6. Приложение не заменяет врача. Диагнозов и лечения не даёт.
7. APK подписан отладочным ключом и не предназначен для Google Play.

## 7. Критерии приёмки

1. Профиль мужчины (35 лет, 183 см, 150 кг, сидячий) даёт норму ≈2370 ккал, женщины (30 лет, 172 см, 120 кг) ≈1890 ккал; ниже 1500/1200 норма не опускается.
2. Добавление продукта из базы и своего рецепта обновляет кольцо калорий.
3. Давление 190/110 блокирует упражнения; два замера 150/95 подряд включают облегчённый режим.
4. Глюкоза 7,4 натощак снижает дефицит до 10%.
5. План недели в среднем совпадает с нормой (±6%), список покупок суммируется по профилям.
6. День засчитывается только при трёх выполненных привычках, один пропуск за неделю замораживается.
7. Уведомления приходят по расписанию при закрытом приложении (проверка: кнопка «Тест», затем расписание).
8. Экспорт → удаление данных → импорт возвращает все записи.
9. Сборка в GitHub Actions завершается зелёным статусом, APK прикрепляется к релизу.

## 8. Развитие (вне первой версии)

Синхронизация с часами и шагами (Health Connect), сканер штрихкодов, фото блюд, облачная синхронизация пары, виджет воды на главном экране, кнопки «+250 мл» прямо в уведомлении, подпись релизным ключом для Google Play.
