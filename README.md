# Легче

Андроид-приложение для безопасного похудения: калории и БЖУ, дневник на 800+ продуктов, вода, вес и замеры, давление и глюкоза с правилами безопасности, план питания и бюджетная корзина, малоударная программа движения, награды за привычки и режим пары. Работает офлайн, данные только на телефоне, напоминания — локальными уведомлениями.

- Техническое задание: [docs/TZ.md](docs/TZ.md)
- Как собрать APK на GitHub: [docs/BUILD.md](docs/BUILD.md)

Быстрый старт: загрузите файлы в репозиторий GitHub → Releases → Create a new release → тег `v1.0.0` → Publish. Через 6–12 минут APK появится в релизе.

Локальная проверка расчётов: `npm install && npm test`. Проверка интерфейса в браузере: откройте `www/index.html`.
